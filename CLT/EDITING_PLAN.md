## R02：定理文に関わる問題

「非負領域へ統一する」は高温の上限を取り除く意味ではない。各結果で必要な上限と端点を照合し、特に `beta = 0` の退化した相対 CLT と、分散で割るためそこで未定義となる標準化 CLT を分ける。候補の温度上限や非退化条件は、確認が済むまで確定した仮定として使わない。

仮定・規格化・温度領域・外部入力の調査は承認前に行える。変更案と根拠をまとめ、定理文や採用する前提を変更する前に人間の研究者の明示的な承認を得る。調査が終わって承認を待つ場合は、ここに判断事項を記し、一覧の状態を「判断待ち」にする。非負逆温度を使う共有模型の方針だけで、原稿の正確な範囲まで承認されたとはみなさない。

- [ ] 相対ゆらぎの CLT が `beta = 0` で持つ退化した極限と、そこで未定義となる標準化した CLT のパラメータ範囲を分けて記述する。
- [ ] Theorem 1.1–1.2、Corollary 1.3 と内部補題の温度領域を `beta >= 0` に統一する。
- [ ] 非負領域で `ell_q'(beta) > 0` を使える、正確な非退化領域を記述する。
- [ ] `beta_FE`、`beta_Rad`、非退化領域、および Theorem 1.1 の適用範囲の関係を明記する。候補となる関係 `beta_q <= min(beta_FE, beta_Rad, beta_nd, tilde_beta_q)` が実際の依存関係を正しく表すか確認する。
- [ ] Theorem 1.1 を原稿内で証明するか、クエンチ量に関する外部結果を引用するか決定する。

完了条件：三つの主結果について、逆温度の範囲と非退化条件が相互に整合する。

## W06：CLT の有限模型との接続

前提は W04・W05（従って W01–W03）。通常のトレースによる複素分配関数とその解析は共有側に実装されており、CLT の局所定義はまだ存在しない。共有模型と集中不等式の再設計中に CLT の雛形へ依存する宣言を追加しない。

- [ ] 完成した標準行列表現と共有ハミルトニアンを使い、`normalizedTrace` から CLT 固有の規格化分配関数を定義する。`Z(0)=1` と共有分配関数を次元で割った量との一致を証明する。
- [ ] CLT が実際に使う整関数性・微分を共有結果から導き、実逆温度での正値性・実対数と分離する。共有側に規格化・非規格化の対応する API を一式追加しない。
- [ ] 実逆温度では通常の対数分配関数との差が `log d` であることを示す。中心化でこの定数が消えることと必要な可積分性を確認する。
- [ ] `W_N = log Y_N` について、`eq:centered W_N tail` と `eq:centered W_N exp` に必要な集中評価を共有結果から移送する。期待値による規格化と次元による規格化を区別し、係数を悪化させない。
- [ ] `β=0` の定数の場合を扱い、正の `β` を分母に持つ裾評価へそのまま代入しない。
- [ ] 複素対数微分を使う場合は `Z z ≠ 0` を明示し、その非零性自体を内部で証明済みと扱わない。零点のない領域の構成は Z01 に分離する。
- [ ] 各変更ファイル、`lake build Model SuperConcentration CLT`、主要定理の公理依存・残る仮定、このディレクトリ内の README・構造文書との整合を検査し、結果を記録する。

担当部分の完了条件：原稿の有限模型と共有定義の対応、必要な解析と集中評価が検査されている。W06 全体では [Chapters の計画](../Chapters/EDITING_PLAN.md) に記す章の更新と検証も必要である。原稿の大数則・各 CLT の最終定理を証明したことにはしない。

## Z01：複素平面上の零点のない領域

細目と進捗は [Model の Z01](../Model/EDITING_PLAN.md#z01) に集約する。CLT 側は必要な円板・帯状領域、一様性、内部証明か外部入力かの要件を供給する。領域が確定する前に、実逆温度の集中不等式や W06 の接続を待たせない。

全複素平面での非零性や複素逆温度の正値性は目標にしない。`Z z ≠ 0` を条件とする API と、その条件を供給する領域の定理を区別する。
