## 現在の範囲

## 残る研究課題

### アニール入力の構築

`Main.lean` の条件付き CLT は、一つの `S : Setting q` と `hFE : AnnealedInput q S` を入力に取る。`AnnealedInput` は原稿 `refs/sections/main-results.tex` の `prop:annealed-free-energy`（Proposition 4.2）に対応し、偶・凸な `C¹` 関数、圧力と導関数の全実軸での局所一様収束、明示的評価、非零逆温度での符号を要求する。この入力をガウス模型族について構築する証明は未完了である。He2026 の引用から原稿が導く範囲、規格化、収束の種類と Lean の各フィールドを改めて照合してから実装する。外部結果そのものを Lean の内部証明と扱わない。

`Annealed_FE/refs/SYK-HT-arxiv.tex` は別の Rademacher 模型の原稿であり、そこでの結果をこの入力の構築と同一視しない。`Annealed_FE` は現在の `CLT/Main.lean` の import 先ではない。

### 具体模型への適用

抽象的な `Setting q` から具体的なガウス SYK 模型族への適用条件を明示する。有限サイズの標準表現と規格化は `Normalization.lean` で照合済みだが、それだけで一般表現についての外部極限定理や `AnnealedInput` が得られるわけではない。対象の族、必要な表現独立性と外部入力の適用範囲を確定してから、具体的な定理文を決める。

### 新たに一様な複素領域を必要とする場合

Z01 は非空有限次元の固定自己共役行列と各実逆温度について局所円板を与える。現行の実逆温度 CLT は複素対数や `N`・乱数標本に一様な非零領域を入力に使わない。新しい利用側が必要とする場合は、領域、行列の範囲、一様性を別課題として指定する。[Z01 の記録](../WORK_HISTORY.md#z01-local-zero-free-2026-09-28)を参照する。

## 新しい作業の仕様

原稿の有効な TeX ラベルと主張、Lean 定理文の型・量化順序・仮定・規格化・結論、先行する証明済み宣言、外部入力、編集担当と検証対象を決める。定理文や外部前提の変更は根拠を示し、人間の研究者の承認を得る。実装では変更ファイルの個別 Lean 検査、関連ビルド、主要定理の公理依存と残る仮定、原稿との対応を確認する。Blueprint の宣言参照はソース上で照合し、Verso の機械的検査は復帰後に行う。

モジュールの検索には [README の案内](README.md#finding-a-lemma)と[構造文書の索引](ARCHITECTURE.md#補助-lean-ファイルの役割)を使う。ディレクトリ再配置や参照専用 API の追加は、実際の探索・利用上の必要が明らかになった場合に検討する。
