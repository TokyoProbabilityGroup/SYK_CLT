# Blueprint 各章の編集計画

## 担当範囲

この文書は、このディレクトリの `Model.lean`、`GaussianConcentration.lean`、`SuperConcentration.lean`、`AnnealedFE.lean`、`CLT.lean` に記す主要な主張と Lean 宣言の対応を管理する。全体の実行順序・状態・並行作業の可否は [全体計画](../EDITING_PLAN.md)、守る条件は [SYK の作業規則](../AGENTS.md) の Blueprint の節を参照する。

各章の更新は対応する実装単位に含める。ここでは上流の数学的な証明を再実装せず、未実装の宣言を実装済みとして参照しない。本文は公開用の英語で記述する。

CLT の F01–F07 に対応する結果と固定した自己共役有限行列に対する Z01 の局所結果は実装済みである。F08 は仕様確定で完了した。`Annealed_FE` には未形式化部分が残る。章の編集は全体計画で指定した統合担当一人が行う。分担者は修正案を提出し、統合担当がコードの統合・検証と原稿照合を終えた範囲について証明状態・宣言参照・依存関係を更新する。Lean に残る外部仮定と `sorryAx` は内部証明と区別する。

## 現行の章と残件

`Model.lean`、`GaussianConcentration.lean`、`SuperConcentration.lean` は共有模型と集中評価の検証済み宣言を参照する。`Model.lean` は Z01 の局所非零円板と主値対数の正則性も参照する。`CLT.lean` は有限模型、ガウス–エルミート展開、高次剰余、および三種類の条件付き CLT をまとめた定理と個別定理を参照する。三つの主 CLT は `0<|β|<β_q` に限定し、`AnnealedInput` の構築を内部証明として扱わない。`AnnealedFE.lean` の未形式化部分は計画として明示する。

現在の章には、原稿の `sec:introduction` と `sec:main-results` の更新前の説明が残る。次の対応修正は未実装であり、関係する実装単位に含める。

- `CLT.lean` の `cor:free-energy-clt` を現行の `thm:free-energy-clt` に更新し、`thm: input` をアニール圧力の極限と極限関数の微分可能性として記述する。現行原稿にない期待クエンチ圧力との共通極限や `\iffalse` 内の旧証明への説明を整理する。
- `AnnealedFE.lean` と `CLT.lean` のアニール入力の説明を、追加6フィールドの削除と Lean の再検証後に現行命題へ合わせる。それまでは変更予定を実装済みとして記さない。
- `lem:convex-derivatives` の補完、対数の期待誤差の明示的評価、外部入力からのアニール入力構築、具体模型への適用は、それぞれの実装・検証後に対応する数学的主張、宣言参照、残る仮定を更新する。
- 共有層の再配置に伴う章の参照変更は数学的実装後のリファクタリングに含める。作業順序は [全体計画](../EDITING_PLAN.md#残る作業)、数学的な仕様は [CLT の計画](../CLT/EDITING_PLAN.md) を参照する。

F01–F07 と Z01 の該当する章は、過去の統合時点で実装済み宣言への参照とソース上の照合を終えた。これは現在の原稿との照合完了を意味しない。Z01 の局所円板は `N`・乱数標本に一様な領域と区別する。日付ごとの編集内容と検証結果は [作業履歴](../WORK_HISTORY.md#chapters-records)、[CLT の統合後検証](../WORK_HISTORY.md#clt-integration-audit-2026-09-29)、[Z01 の検証](../WORK_HISTORY.md#z01-local-zero-free-2026-09-28)を参照する。Verso による章検査・生成・参照検査は休止中である。

## 原稿改訂への対応

原稿のどの箇所の改訂でも [全体計画の同期手順](../EDITING_PLAN.md#原稿改訂と実装の同期) に従う。統合担当は改訂された主張・証明・引用と、[CLT の記法対応](../CLT/ARCHITECTURE.md#原稿推敲と記法の対応) を確認し、章の説明・依存関係・TeX ラベル・Lean 宣言との対応を更新する。原稿の記号変更だけを理由に Lean 宣言の改名を要求しない。

実装の証明状態を変えない記法・参照の修正は、原稿との対応確認後に反映してよい。未統合の実装を検証済みとして記載する変更とは区別する。改訂中または未照合の差分が残る場合は、照合した原稿の範囲と未確認箇所を明記する。

## 検証と記録

Verso 休止中は、変更した章の数学的主張・Lean 宣言名・依存名をソース上で照合する。Verso を必要とする章と生成入口の Lean 検査、生成、`vbp check` は復帰後に休止中の変更を含めて行う。分担者の修正案を統合担当が直列に反映する。

検証記録は [全体計画](../EDITING_PLAN.md#識別情報と検証対象の記録) に従い、章では照合した宣言と未解決の参照も記録する。過去の検証結果と旧コマンドは [作業履歴](../WORK_HISTORY.md#chapters-records) を参照する。
