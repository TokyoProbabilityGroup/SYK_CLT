# Blueprint: the sharp centered MGF bound

This file describes only the implementation of

```text
E exp(t (X_N - E X_N)) ≤ exp(t² ε_N / 2),    t ∈ ℝ.
```

Tail estimates, variance bounds, the relative partition function, Wiener chaos,
and the partition-function CLT are outside the scope of this blueprint.

## Target

Fix an even interaction order `q ≥ 4`, a system size `N ≥ q`, inverse
temperature `β`, and standard Gaussian couplings

```text
g : CouplingSpace N q.
```

Let

```text
σ_N² = (q - 1)! / N^(q - 1),
H_N(g) = σ_N ∑_I g_I Γ_I,
X_N(g) = log Z_N(β; g).
```

The goal is a theorem of the following form, with `μ` the repository's product
standard Gaussian measure:

```lean
theorem logPartition_centered_mgf_le
    (P : CLT.FixedParameters) (k : ℕ) (β t : ℝ) :
    mgf
        (fun g ↦ logPartitionR P k β g -
          ∫ h, logPartitionR P k β h
            ∂standardGaussianMeasure (CLT.systemSize P k) P.q)
        (standardGaussianMeasure (CLT.systemSize P k) P.q) t ≤
      Real.exp
        ((superConcentrationScale P k β : ℝ) * t ^ 2 / 2)
```

Here

```text
ε_N = superConcentrationScale P k β
```

must be explicit and satisfy

```text
ε_N = C_{β,q} N^(1-q/2).
```

For Lean, avoid negative natural exponents. Define the finite-volume quantity as

```text
ε_N = β² (q-1)! C_{β,q} N^(q/2) / N^(q-1),
```

then prove the displayed power-law identity or asymptotic estimate separately if it
is ever needed. The MGF theorem itself should use the exact finite-volume expression.

## Existing code to reuse

The following files already contain the required general infrastructure:

```text
SYK/super_concentration/core.lean
SYK/super_concentration/gibbs.lean
SYK/super_concentration/super_conc.lean
SYK/super_concentration/Gaussian_concentration/gaussian_concentration.lean
```

In particular, the Gaussian module already proves

```lean
theorem product_standardGaussian_mgf_le
    (F : EuclideanSpace ℝ ι → ℝ) (L : ℝ) (hL : 0 < L)
    (hLip : LipschitzWith L.toNNReal F) (t : ℝ) :
    mgf (fun x ↦ F x - ∫ y, F y ∂standardGaussianMeasureOnEuclidean ι)
        (standardGaussianMeasureOnEuclidean ι) t ≤
      Real.exp (L ^ 2 * t ^ 2 / 2)
```

Therefore no new Gaussian concentration proof is needed. The task is to prove the
sharp Lipschitz-square estimate for the SYK log partition function and instantiate
this theorem with `L = sqrt ε_N`.

The concrete sequence is defined in `SYK/CLT/main_result.lean`. Reuse
`CLT.FixedParameters`, `CLT.systemSize`, `CLT.matrixMajorana`,
`CLT.gaussianHamiltonian`, and `CLT.partitionFunctionR`. Do not duplicate the model.

It is convenient to add

```lean
noncomputable def logPartitionR
    (P : CLT.FixedParameters) (k : ℕ) (β : ℝ)
    (g : CouplingSpace (CLT.systemSize P k) P.q) : ℝ :=
  Real.log (CLT.partitionFunctionR P k β g)
```

after proving that `CLT.partitionFunctionR P k β g` is strictly positive.
Normalization of the matrix trace changes `log Z_N` only by a deterministic
constant, so it has no effect after centering.

## The one new mathematical input

The existing theorem `syk_sum_sq_expectation_le` applies to every density matrix and
has size `choose N (q-1) / q`. It yields only a dimension-free concentration scale.
It cannot imply the requested power of `N`.

The sharper result requires a Gibbs-specific estimate. Introduce the Gibbs moments

```text
m_I(g) = Tr(ρ_{β,g} Γ_I)
```

using `thermalDensity` and `MajoranaSystem.interactionOperator`, and prove an explicit
finite-volume theorem of the form

```lean
theorem gibbs_majorana_moment_sq_le
    (P : CLT.FixedParameters) (k : ℕ) (β : ℝ)
    (g : CouplingSpace (CLT.systemSize P k) P.q) :
    ∑ I, ‖gibbsMajoranaMoment P k β g I‖ ^ 2 ≤
      majoranaMomentConstant P β *
        (CLT.systemSize P k : ℝ) ^ (P.q / 2)
```

The constant must be nonnegative, independent of `k` and `g`, and explicit enough
to define `superConcentrationScale`. This theorem is the substantive missing result.
Do not state it for arbitrary density matrices.

The current `Params` API packages a nonnegative inverse temperature. Either state the
first implementation for `0 ≤ β`, or reduce negative `β` to positive `-β` by the
measure-preserving substitution `g ↦ -g`. Do not silently coerce an arbitrary real
temperature to `NNReal`.

## From Gibbs moments to the Lipschitz constant

The affine-line derivative already developed in `super_conc.lean` gives

```text
D X_N(g)[v] = -β σ_N ∑_I v_I m_I(g).
```

Cauchy–Schwarz and `gibbs_majorana_moment_sq_le` give

```text
|D X_N(g)[v]|²
  ≤ β² σ_N² ‖v‖² ∑_I |m_I(g)|²
  ≤ ε_N ‖v‖².
```

Define a nonnegative scale, preferably in `ℝ≥0`:

```lean
noncomputable def superConcentrationScale
    (P : CLT.FixedParameters) (k : ℕ) (β : ℝ) : ℝ≥0 :=
  ⟨β ^ 2 * Nat.factorial (P.q - 1) * majoranaMomentConstant P β *
      (CLT.systemSize P k : ℝ) ^ (P.q / 2) /
      (CLT.systemSize P k : ℝ) ^ (P.q - 1), by positivity⟩
```

Adjust coercions to the final type of `majoranaMomentConstant`. Since
`CLT.systemSize P k ≥ P.q ≥ 4`, the denominator is positive.

Prove the directional bound directly:

```lean
theorem logPartition_directional_sq_le_superConcentration ... :
    |D X_N(g)[v]| ^ 2 ≤
      (superConcentrationScale P k β : ℝ) * ‖v‖ ^ 2
```

Then reuse the affine-line mean-value argument from `logPartition_lipschitz`; a full
Fréchet derivative or an explicit gradient is unnecessary.

```lean
theorem logPartition_lipschitz_superConcentration ... :
    LipschitzWith (superConcentrationScale P k β).sqrt
      (logPartitionR P k β)
```

Keep the exact square throughout the proof. This avoids losing the sharp constant by
replacing the finite-volume scale with a coarser upper bound.

## Final MGF assembly

When `0 < ε_N`, apply `product_standardGaussian_mgf_le` with

```text
F = logPartitionR P k β,
L = sqrt ε_N.
```

Use `Real.sq_sqrt` and nonnegativity of `ε_N` to rewrite

```text
L² t² / 2 = ε_N t² / 2.
```

The Gaussian theorem is valid for every `t : ℝ`, so the final result must not add
a sign hypothesis on `t`.

When `ε_N = 0`, prove that `X_N` is constant and simplify the MGF directly. In the
intended formula this includes `β = 0`. This separate branch is needed because
`product_standardGaussian_mgf_le` assumes a strictly positive Lipschitz constant.

The completed theorem is the endpoint of this project. Do not add tail, variance,
relative-partition, or chaos corollaries to this blueprint.
