# Lean blueprint for the SYK superconcentration bound

## Target

The first formal target should be the exact finite-dimensional inequality

$
\sum_{|I|=q}\left|\operatorname{Tr}(\rho\Gamma_I)\right|^2
\le \frac{1}{q}\binom{N}{q-1},
$

where $q>0$ is even, $\rho$ is a density matrix, and
$\Gamma_I=i^{q/2}\prod_{j\in I}\chi_j$ is the Hermitian Majorana monomial
already represented by `phase` and `MajoranaSystem.chiProduct` in
`SYK/lean_files/model.lean`.

The asymptotic statement $O(N^{q-1})$ should be a corollary of this exact
bound. The exact theorem is more useful in later gradient estimates and is
easier to reuse in Lean.

The algebraic theorem does not depend on the Hamiltonian, inverse temperature,
or probability. Prove it for an arbitrary density matrix before connecting it
to `gibbsOperator`.

## Corrections and representation decisions

- Use the Gibbs sign from `model.lean`: $\rho=e^{-\beta H}/Z$.
- Use `phase q = Complex.I ^ (q / 2)`. For even $q$, this equals the alternate
  phase $i^{q(q-1)/2}$.
- Work with `Matrix d d ℂ` for the density-matrix part. The current abstract
  `MajoranaSystem` does not contain positivity or a trace.
- State squared absolute values as real numbers with
  `‖expectation ρ A‖ ^ 2`.
- Keep the Gaussian concentration theorem separate. The local mathlib version
  has Gaussian distribution APIs, but no immediately reusable theorem giving
  the required concentration inequality for every Euclidean Lipschitz map.

## Project setup

To import the existing model by module name, add a library entry to
`lakefile.lean`:

```lean
lean_lib SYK where
  srcDir := "."
  globs := #[.submodules `SYK]
```

Then start `SYK/super_concentration/super_conc.lean` with imports close to:

```lean
import SYK.lean_files.model
import Mathlib.Analysis.CStarAlgebra.Matrix
import Mathlib.Analysis.Matrix.PosDef
import Mathlib.Data.Fintype.Powerset
import Mathlib.Data.Nat.Choose.Bounds
```

`Mathlib.Analysis.Matrix.PosDef` supplies the analytic positive-semidefinite
matrix API. `Fintype.card_finset_len` gives the number of fixed-cardinality
finsets, and `Nat.choose_le_pow` or `Nat.choose_le_pow_div` gives the final
polynomial bound.

The signatures below are intended as stable targets. Small changes in explicit
coercions or namespaces may be needed while compiling.

## Density matrices and expectations

Introduce a small interface in the matrix section:

```lean
namespace SYK

open scoped BigOperators ComplexConjugate

section DensityMatrix

variable {d : Type*} [Fintype d] [DecidableEq d]

def IsDensityMatrix (ρ : Matrix d d ℂ) : Prop :=
  ρ.PosSemidef ∧ Matrix.trace ρ = 1

def expectation (ρ A : Matrix d d ℂ) : ℂ :=
  Matrix.trace (ρ * A)

end DensityMatrix

end SYK
```

Using a predicate rather than a subtype keeps theorem statements and rewriting
simple. A subtype can be added later if many functions need to carry the same
hypotheses.

Prove these foundational lemmas:

```lean
theorem expectation_star_eq
    (hρ : IsDensityMatrix ρ) (hA : star A = A) :
    star (expectation ρ A) = expectation ρ A

theorem expectation_im_eq_zero
    (hρ : IsDensityMatrix ρ) (hA : star A = A) :
    (expectation ρ A).im = 0

theorem expectation_eq_ofReal_re
    (hρ : IsDensityMatrix ρ) (hA : star A = A) :
    ((expectation ρ A).re : ℂ) = expectation ρ A
```

For `expectation_star_eq`, use `Matrix.trace_conjTranspose`, the Hermitian part
of `hρ.1`, `hA`, and `Matrix.trace_mul_comm`. This lemma is required because
the coefficients in the anticommuting-family argument must be real.

## The variance lemma

The paper proof uses the operator norm inequality
$|\operatorname{Tr}(\rho B)|\leq\|B\|$. A shorter Lean route is positivity of
variance. Prove:

```lean
theorem density_variance_nonneg
    (hρ : IsDensityMatrix ρ) (hB : star B = B) :
    0 ≤ (expectation ρ (B * B)).re - (expectation ρ B).re ^ 2
```

Suggested proof construction:

- Set `x : ℝ := (expectation ρ B).re`.
- Set `C := B - (x : ℂ) • (1 : Matrix d d ℂ)`.
- Show `star C = C`.
- From `hρ.1.conjTranspose_mul_mul_same C`, obtain that
  `Cᴴ * ρ * C` is positive semidefinite.
- Apply `Matrix.PosSemidef.trace_nonneg`.
- Rewrite the trace by cyclicity, expand `C`, use `Matrix.trace_mul_comm`, and
  use `hρ.2` and `expectation_eq_ofReal_re`.
- Finish the real polynomial identity with `ring_nf` or `nlinarith`.

This isolates all positivity work in one lemma. No matrix square root or
operator-norm estimate is needed for the main result.

## Majorana observables

Define the phase-corrected interaction observable in the existing namespace:

```lean
namespace MajoranaSystem

noncomputable def interactionOperator
    (M : MajoranaSystem N A) (s : InteractionIndex N q) : A :=
  phase q • M.chiProduct s

end MajoranaSystem
```

The following algebraic lemmas should be proved for the abstract algebra when
possible. This makes the matrix theorem only a specialization.

```lean
theorem majorana_sq (i : Fin N) :
    M.χ i * M.χ i = 1

theorem chiProduct_sq (s : InteractionIndex N q) :
    M.chiProduct s * M.chiProduct s =
      ((-1 : ℂ) ^ (q * (q - 1) / 2)) • 1

theorem interactionOperator_star
    (hq : Even q) (s : InteractionIndex N q) :
    star (M.interactionOperator s) = M.interactionOperator s

theorem interactionOperator_sq
    (hq : Even q) (s : InteractionIndex N q) :
    M.interactionOperator s * M.interactionOperator s = 1
```

`majorana_sq` follows from `majorana_rel i i`; normalize the two occurrences of
the same product and cancel the nonzero complex scalar $2$. For
`chiProduct_sq`, induction on the sorted list is preferable to a large
commutative-ring calculation. Moving the head generator across the tail gives
one sign per tail element.

`interactionOperator_star` should reuse
`MajoranaSystem.star_chiProduct_of_even` and the existing phase identity. The
current theorem `star_phase_mul_sign` is private, so either put these new
observable lemmas in `model.lean` or make that scalar identity public first.
For `interactionOperator_sq`, combine `chiProduct_sq` with the scalar phase
identity

$
(i^{q/2})^2(-1)^{q(q-1)/2}=1.
$

Also prove the monomial commutation formula:

```lean
theorem chiProduct_mul_comm_sign
    (s : InteractionIndex N r) (t : InteractionIndex N k) :
    M.chiProduct s * M.chiProduct t =
      ((-1 : ℂ) ^ (r * k - (s.1 ∩ t.1).card)) •
        (M.chiProduct t * M.chiProduct s)
```

The same formula for `interactionOperator` follows because complex scalars are
central. Prove the list version first, then rewrite the sorted lists back to
finsets. The exponent counts pairs of distinct generators; a generator in the
intersection is not swapped with itself.

If the general intersection formula takes too much code, it is acceptable to
prove only the fixed-core specialization below. The final theorem needs no
other case.

## Fixed-core family

For a $(q-1)$-subset $A$, index the remaining labels by a subtype:

```lean
abbrev Outside (A : InteractionIndex N (q - 1)) :=
  {j : Fin N // j ∉ A.1}

def extendInteraction
    (hq : 0 < q) (A : InteractionIndex N (q - 1)) (j : Outside A) :
    InteractionIndex N q :=
  ⟨insert j.1 A.1, by
    rw [Finset.card_insert_of_notMem j.2, A.2]
    omega⟩
```

The exact arithmetic proof may instead use `Nat.sub_add_cancel hq` after
turning `hq` into `1 ≤ q`.

Prove the fixed-core anticommutation theorem:

```lean
theorem extendInteraction_anticommute
    (hq0 : 0 < q) (hq : Even q)
    (A : InteractionIndex N (q - 1))
    (j k : Outside A) (hjk : j ≠ k) :
    M.interactionOperator (extendInteraction hq0 A j) *
        M.interactionOperator (extendInteraction hq0 A k) =
      -(M.interactionOperator (extendInteraction hq0 A k) *
        M.interactionOperator (extendInteraction hq0 A j))
```

Useful intermediate facts are:

```lean
(insert j.1 A.1 ∩ insert k.1 A.1) = A.1
(insert j.1 A.1).card = q
(insert k.1 A.1).card = q
Odd (q - 1)
```

The intersection equality is an extensional `simp` proof using `j.2`, `k.2`,
and `hjk`. The sign exponent is odd because $q^2$ is even and $q-1$ is odd.

## Generic anticommuting-family estimate

Prove a theorem independent of Majorana operators:

```lean
theorem sum_sq_expectation_le_one
    {ι d : Type*} [Fintype ι] [Fintype d] [DecidableEq d]
    (ρ : Matrix d d ℂ) (A : ι → Matrix d d ℂ)
    (hρ : IsDensityMatrix ρ)
    (hstar : ∀ i, star (A i) = A i)
    (hsq : ∀ i, A i * A i = 1)
    (hanti : ∀ i j, i ≠ j → A i * A j = -(A j * A i)) :
    ∑ i, ‖expectation ρ (A i)‖ ^ 2 ≤ 1
```

Proof plan without operator norms:

- Work classically and set `x i := (expectation ρ (A i)).re`.
- Set `s := ∑ i, (x i) ^ 2` and
  `B := ∑ i, ((x i : ℂ) • A i)`.
- Use `hstar` to show `star B = B`.
- Show `B * B = (s : ℂ) • 1` from `hsq` and `hanti`.
- Show `expectation ρ B = (s : ℂ)` by linearity of trace and
  `expectation_eq_ofReal_re`.
- Apply `density_variance_nonneg hρ` to `B`.
- Rewrite both expectations using the preceding two identities. This gives
  $0\leq s-s^2$.
- Since `s` is a sum of squares, `nlinarith` gives $s\leq1$.
- Rewrite `‖expectation ρ (A i)‖ ^ 2` as `(x i) ^ 2` using
  `expectation_eq_ofReal_re` and `Complex.norm_real`.

For the identity for `B * B`, induction over `Finset.univ` is likely simpler
than manipulating a double sum. When inserting one new index, the two cross
terms cancel by `hanti`, and the square term reduces with `hsq`.

## Double-counting equivalence

Package the combinatorics as a reusable equivalence. Define

```lean
abbrev ChosenPoint (I : InteractionIndex N q) :=
  {j : Fin N // j ∈ I.1}
```

Then construct

```lean
def extensionEquiv (hq : 0 < q) :
    (Σ A : InteractionIndex N (q - 1), Outside A) ≃
      (Σ I : InteractionIndex N q, ChosenPoint I)
```

The forward map sends $(A,j)$ to $(A\cup\{j\},j)$. The inverse sends $(I,j)$
to $(I\setminus\{j\},j)$. Use `Finset.erase_insert`,
`Finset.insert_erase`, `Finset.card_erase_of_mem`, and subtype extensionality
for the inverse laws.

Derive the summation identity:

```lean
theorem sum_over_extensions
    (hq : 0 < q) (f : InteractionIndex N q → ℝ) :
    ∑ A : InteractionIndex N (q - 1),
      ∑ j : Outside A, f (extendInteraction hq A j) =
    (q : ℝ) * ∑ I : InteractionIndex N q, f I
```

Use `Fintype.sum_equiv extensionEquiv`. On the right, the inner sum is constant
and `Fintype.card (ChosenPoint I) = I.1.card = q`.

This equivalence is safer than proving informally that every $q$-subset occurs
$q$ times.

## Exact SYK theorem

The main algebraic theorem should have a signature close to:

```lean
theorem syk_sum_sq_expectation_le
    {N q : ℕ} (hq0 : 0 < q) (hq : Even q)
    {d : Type*} [Fintype d] [DecidableEq d]
    (M : MajoranaSystem N (Matrix d d ℂ))
    (ρ : Matrix d d ℂ) (hρ : IsDensityMatrix ρ) :
    ∑ I : InteractionIndex N q,
        ‖expectation ρ (M.interactionOperator I)‖ ^ 2 ≤
      (Nat.choose N (q - 1) : ℝ) / q
```

The proof is a short composition of earlier lemmas:

- For every `A : InteractionIndex N (q - 1)`, apply
  `sum_sq_expectation_le_one` to the family indexed by `Outside A`.
- Sum these inequalities over `A`.
- Rewrite the left side with `sum_over_extensions`.
- Rewrite the number of cores with `Fintype.card_finset_len` and
  `Fintype.card_fin N`.
- Divide by the positive real number `(q : ℝ)` using `hq0`.

A wrapper accepting `P : Params` can pass `P.q_pos` and `P.q_even`. The pure
theorem should not depend on `P.β`.

## Polynomial corollary

First prove a pointwise estimate rather than introducing asymptotic notation:

```lean
theorem syk_sum_sq_expectation_le_pow ... :
    ∑ I : InteractionIndex N q,
        ‖expectation ρ (M.interactionOperator I)‖ ^ 2 ≤
      (N : ℝ) ^ (q - 1) / q
```

This follows from `Nat.choose_le_pow N (q - 1)` after casting to `ℝ`. If an
explicit big-O theorem is later required, use `isTheta_choose (q - 1)` from
`Mathlib.Analysis.SpecialFunctions.Choose`, or derive big-O directly from the
pointwise estimate.

## Connection to the Gibbs state

Do this only after the arbitrary-density theorem compiles. Add a normalized
matrix, distinct from the existing scalar-valued `gibbsState`:

```lean
noncomputable def thermalDensity
    (β : NNReal) (H : Matrix d d ℂ) : Matrix d d ℂ :=
  (partitionFunction β H)⁻¹ • gibbsOperator β H
```

Required bridge lemmas are:

```lean
theorem gibbsOperator_posSemidef
    (hH : star H = H) : (gibbsOperator β H).PosSemidef

theorem partitionFunction_pos
    [Nonempty d] (hH : star H = H) :
    0 < (partitionFunction β H).re

theorem thermalDensity_isDensityMatrix
    [Nonempty d] (hH : star H = H) :
    IsDensityMatrix (thermalDensity β H)

theorem gibbsState_eq_expectation_thermalDensity
    [Nonempty d] (hH : star H = H) :
    gibbsState β H O = expectation (thermalDensity β H) O
```

`Matrix.IsHermitian.exp` already proves Hermiticity of the matrix exponential.
Strict positivity of its eigenvalues can be proved with the Hermitian spectrum
API in `Mathlib.Analysis.Matrix.Spectrum`. Keep this spectral work out of the
generic anticommuting-family theorem.

## Optional gradient and Gaussian layer

For the normalized Hamiltonian

$
H(J)=a_{N,q}\sum_I J_I\Gamma_I,
\qquad
a_{N,q}=\mathcal J\sqrt{\frac{(q-1)!}{N^{q-1}}},
$

the derivative identity should be isolated as:

```lean
theorem fderiv_logPartition_apply ... :
    fderiv ℝ logPartition J v =
      -β * aNq * ∑ I, v I *
        (expectation (thermalDensity β H) (M.interactionOperator I)).re
```

The exact superconcentration theorem then gives

$
\|\nabla\log Z\|_2^2
\leq \beta^2 a_{N,q}^2\frac{1}{q}\binom{N}{q-1}
\leq \frac{\beta^2\mathcal J^2}{q}.
$

For the last inequality, use `Nat.choose_le_pow_div (α := ℝ) (q - 1) N`.
This is the improved Lipschitz estimate. The coordinatewise estimate in the
old note only gives a bound of order $N$ and does not use superconcentration.

Formalizing the derivative of `Matrix.exp`, the real positivity of the
partition function, and the Gaussian isoperimetric inequality are independent
projects. They should not block the exact sum-of-squares theorem.

## Recommended implementation order

Use this dependency order:

```text
IsDensityMatrix and expectation
  -> expectation is real on Hermitian matrices
  -> density_variance_nonneg
  -> sum_sq_expectation_le_one

majorana_sq
  -> chiProduct_sq
  -> interactionOperator_sq

chiProduct commutation sign
  -> fixed-core anticommutation

extendInteraction and extensionEquiv
  -> sum_over_extensions

generic estimate + fixed-core family + counting
  -> syk_sum_sq_expectation_le
  -> polynomial corollary

Gibbs positivity and normalization
  -> thermal-state specialization

log-partition derivative + Gaussian concentration input
  -> final probability tail bound
```

The first completion milestone is `syk_sum_sq_expectation_le` for an arbitrary
density matrix. It contains the main algebraic and combinatorial content and
does not require probability theory.
