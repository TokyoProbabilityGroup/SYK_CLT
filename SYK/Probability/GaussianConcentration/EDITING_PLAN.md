# 汎用ガウス集中不等式の保守課題

探索タクティク（`aesop`・`grind`）と非推奨 API は整理済みで、`maxHeartbeats` の引き上げは `gaussianReal_stein` の1か所（既定値の2倍）だけが残る。残る課題は、書式の警告（長い行、`refine'`、柔軟な `simp`）の解消である。独立した保守作業として扱う。状態と割当は [全体計画](../../../EDITING_PLAN.md#残る作業) に集約する。

公開定理の型・仮定・結論、MGF のパラメータ `L²` と `L=0` の扱いを保持する。模型や CLT の入力・逆向きの import を汎用基盤へ導入しない。現行 API と定数は [構造説明](../../SuperConcentration/ARCHITECTURE.md#汎用的な基盤部分の分離) と Lean ソースを確認する。

完了条件は、対象の警告を解消し、変更ファイル・直接の利用側の個別検査、関連ビルドと `lake build SYK`、主要定理の型・公理依存の照合を終えることである。残した警告とその理由を報告する。過去の独立化と部分積分の共有化は [作業履歴](../../../WORK_HISTORY.md#gaussian-foundation) に記す。
