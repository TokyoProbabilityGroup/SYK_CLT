## 役割と正式な参照元

このディレクトリは複数の研究課題が共有する有限次元 SYK 模型の API を提供する。一般の有限次元模型の規約は講義ノート、CLT 固有の追加条件と規格化は CLT 原稿、実装済み API の正確な型と検証状態は Lean のソースコードを正式な参照元とする。これらが一致しない場合は黙って統合せず、相違を報告する。

講義ノートにある、大きな `N` におけるダイアグラムを用いた解析、Schwinger–Dyson 方程式、共形極限、Schwarzian 有効理論などの発見的な議論に基づく主張を、有限の `N` に対する Lean の定理の根拠として使用しない。

## 保護する模型規約

模型を編集する前に `ARCHITECTURE.md` の「固定する模型規約」を照合し、反交換関係・自己共役性、積の順序と位相、分散、ギブス因子の符号、トレース、型と量化範囲を明示的な承認なしに変更しない。

タプルと `Finset` の対応では積の昇順を明示する。共有模型は偶数 `q >= 2` を扱い、CLT の `q >= 4`、高温条件、ガウスカオスなどを基本構造に組み込まない。規格化・非規格化トレースには異なる名前を使う。

## 各層の役割と境界

抽象的な `MajoranaSystem`、有限行列による具体的な実現、確定的なハミルトニアン、ガウス分布に従うランダムな相互作用、行列を用いた熱力学を区別する。抽象的なマヨラナの関係式だけから従う結果と、既約性、行列の次元、規格化トレースから定まる内積に関する演算子族の直交性を必要とする結果を混同しない。

有限個の座標を持つユークリッド空間上の汎用的なガウス集中不等式は、`SYK/Probability/GaussianConcentration/` に完全に分離する。ガウス分布に従う相互作用係数を SYK 模型に適用するための定義や結果は共有模型側に置くが、CLT 固有のカオス成分への射影や漸近定理は置かない。両トレースの変換は明示し、暗黙の定数倍として扱わない。

## 解析・物理部分の変更前の確認

`ARCHITECTURE.md` の「現行の実装」と「複素逆温度を扱う定理の仮定」に従う。解析は `z : ℂ`、物理的な量は `β : ℝ≥0` に分離する。`Z z ≠ 0` を必要とする結果では仮定を明記し、密度行列の性質を複素逆温度に一般化しない。標準行列表現の性質を抽象的な `MajoranaSystem` に暗黙に追加しない。

モジュールのパスは `SYK.Model` とする。古典系の有限和を対象とする API は導入しない。

## 公開 API の変更

公開する定義、構造体のフィールド、定理文を変更する前に、`rg` で利用箇所をすべて確認し、型、規格化、インポートによる依存関係への影響を説明する。変更後は実際の利用側の関連ビルドを確認し、既存の未完成証明と新たなエラーを区別して報告する。

## 検証

Lean ファイルを変更した場合は、上位の個別 Lean 検査・公理依存確認に加え、`lake build SYK` と影響する利用側の最小のビルド対象を実行する。既定ビルドの対象・除外状態は [全体計画](../../EDITING_PLAN.md#既定ビルドからの一時除外) を確認する。
