# AGENTS.md

## 適用範囲と参照先

`SYK/Model/` 以下に適用し、ワークスペースと [リポジトリの規則](../../AGENTS.md) を追加して守る。変更に関係する [全体計画](../../EDITING_PLAN.md)、[構造文書](ARCHITECTURE.md)、`../../Notes/note.tex`、利用側の Lean 宣言を確認する。CLT の規格化に関係する場合は `../../Paper/sections/introduction.tex` の `subsec:SYK-model` も照合する。

一般有限模型の規約は講義ノート、CLT 固有の条件・規格化は論文、実装の正確な型・証明項は Lean ソースを参照する。不一致は報告する。大きな `N` のダイアグラム、Schwinger–Dyson 方程式、共形極限、Schwarzian 有効理論などの発見的議論を有限 `N` の定理の根拠に使わない。

## 保護する模型規約

[固定する模型規約](ARCHITECTURE.md#固定する模型規約) の反交換関係・自己共役性・積の順序と位相・分散・ギブス因子の符号・トレース・型と量化を、承認範囲外で変更しない。タプルと `Finset` の対応では昇順を明示し、規格化・通常トレースには異なる名前を使う。共有模型へ CLT の `q ≥ 4`・高温・カオスの仮定を組み込まない。

抽象マヨラナ系、標準行列表現、確定的ハミルトニアン、ガウス相互作用、行列の熱力学を区別する。標準表現の次元・直交性や既約性を抽象 `MajoranaSystem` に暗黙に要求しない。

解析は `z : ℂ`、物理量は `β : ℝ≥0` とする。[複素逆温度の仮定](ARCHITECTURE.md#複素逆温度を扱う定理の仮定) を照合し、必要な `Z z ≠ 0` を明記する。密度行列の性質を複素温度へ一般化しない。古典系の有限和 API は導入しない。

## 依存と検証

汎用ガウス集中は `SYK/Probability/GaussianConcentration/`、模型への特殊化は Model、CLT 固有の射影・漸近は CLT に置く。両トレースの変換は明示する。モジュールは `SYK.Model.*`、主要宣言は `SYK` に置く。

公開 API の変更前に `rg` で利用箇所を確認し、型・規格化・依存への影響を説明する。変更ファイルの個別検査に加え `lake build SYK` と影響する利用側の最小対象を実行し、主要定理の公理依存と原稿の対応を確認する。既存の未完成箇所と新たなエラーを区別する。
