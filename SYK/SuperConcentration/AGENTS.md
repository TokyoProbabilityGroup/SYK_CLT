## 適用範囲と参照先

`SYK/SuperConcentration/` 以下に適用する。ワークスペースと [リポジトリの規則](../../AGENTS.md) も適用する。課題に関係する [全体計画](../../EDITING_PLAN.md)、[構造文書](ARCHITECTURE.md)、[模型規約](../Model/ARCHITECTURE.md#固定する模型規約) と Lean ソースを確認する。Model やガウス基盤を編集する場合はそれぞれの規則も適用する。

## 数学と依存の境界

有限型上のガウス測度・Herbst の議論・平滑化・リプシッツ集中は独立した `Probability/GaussianConcentration` 基盤、`CouplingSpace` とその測度は Model に置く。この層には密度行列の評価、相互作用演算子の期待値の二乗和、物理的な逆温度での対数分配関数のリプシッツ評価と集中への適用を置く。

[SYK 固有の証明](ARCHITECTURE.md#syk-に固有の証明) の規格化・座標・有限サイズ二乗和・ギブス微分・MGF と裾の定数を保つ。有効な上界を最良定数と呼ばない。`β=0` は定数関数として処理し、密度行列・実対数・裾の性質を複素逆温度に一般化しない。一般スケール `𝒥` は基本 API に含めず、必要なら係数のスカラー倍から導く。

旧計画との相違は必要時に [履歴](../../WORK_HISTORY.md#super-legacy) を確認し、旧記述を根拠に証明や API を後退させない。
