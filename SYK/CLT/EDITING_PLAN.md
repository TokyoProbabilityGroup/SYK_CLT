# SYK 中心極限定理の未完了作業

条件付き CLT の現行仕様・原稿との対応は [構造文書](ARCHITECTURE.md)、完了した実装と検証は [作業履歴](../../WORK_HISTORY.md) を参照する。ここでは `AnnealedInput` の構築に残る3課題を管理し、状態・担当は [全体計画](../../EDITING_PLAN.md#残る作業) に集約する。

## その他の残件

次の課題は保留中であり、条件付き CLT の検証済み結果とは区別する。依頼を受けて再開する際に対象・編集範囲・検証条件を具体化する。

### 凸関数列の収束補題の補完

対象は保留中の `CLT-CONVEX`。再開時の編集候補は `../Analysis/ConvexDerivatives.lean`。既存の公開定理の型を保持し、不足部分を追加する。個別 Lean 検査と `lake build SYK` も完了条件に含める。

現行の `lem:convex-derivatives` は、全実軸上の微分可能な凸関数列の各点収束と `C¹` 極限から、関数・導関数の局所一様収束を結論する。既存の `convex_convergence_deriv_tendstoUniformlyOn` は関数の局所一様収束を仮定しており、補題全体の形式化ではない。

既存の導関数収束定理を再利用し、各点収束から関数の局所一様収束を導く部分を補い、原稿の全実軸での主張を証明する。原稿の証明省略を理由に外部仮定へ置き換えない。既存の開集合上の定理を維持してよく、不要な一般化は行わない。完了条件は正確な原稿の仮定から両方の局所一様収束を Lean が受理し、主要定理の公理依存を確認することである。

### 外部入力と構築仕様の調査

対象は保留中の `CLT-EXTERNAL`。再開時は参照原稿と引用元の版を定め、`Normalization.lean` と既存の入力宣言を読み取り調査する。引用元の版・定理文・規格化・温度範囲・収束・正則性と各フィールドの導出を照合し、残す外部仮定、内部で証明する補題、不足事項、後続の定理文・編集範囲・検証案を報告する。新しい仮定の採用や実装は行わない。

統合担当が調査結果を構造文書と後続仕様に反映する。新たな外部仮定の採否を研究者が判断し、公開定理の仮定と結論、編集ファイルを確定するまで、命題の証明に着手しない。

### `prop:annealed-free-energy` の証明

対象は保留中の `CLT-ANNEALED`。構築定理の正確な型と編集範囲は外部入力の調査後に確定する。現段階の説明だけから API や新規ファイルを作らない。

`Main.lean` の条件付き CLT は、一つの `S : Setting q` と `hFE : AnnealedInput q S` を入力として受け取る。`prop:annealed-free-energy` の内容をこの仮定として扱い、命題自体の Lean 証明は保留する。再開する場合は、現行の命題文を対象とし、He2026 から受け取る結果と原稿内で導く結果を分離する。対象模型、規格化、逆温度の範囲、正則性、収束の種類を確定してから、明示した外部入力から各フィールドを導く。

He2026 の定理自体の全面的な Lean 形式化は現在の計画に含めない。外部結果は名前を付けた明示的な仮定として受け取り、未検証の公理を導入しない。外部入力そのもの、そこからの導出、`AnnealedInput` を用いた条件付き CLT を別々に記録する。必要な導出が得られない場合は、数学的障害と追加判断・再開条件を報告する。完了条件は、確定した外部仮定から入力を構築し、公理依存とは別に残る仮定を確認することである。

独立した Rademacher 模型の `Annealed_FE` は承認済み構成変更で削除した。ガウス模型の `AnnealedInput` は引き続き明示的な入力とし、その構築を完了済みとしない。

## 着手と検証

原稿の改訂との同期と分担時の引き継ぎは [リポジトリの規則](../../AGENTS.md#原稿の改訂と実装の同期) に従う。補題探索には [README の案内](README.md#finding-a-lemma) と [構造文書の索引](ARCHITECTURE.md#補助-lean-ファイルの役割) を使う。

実装では関係する原稿の仮定・結論と Lean の型を照合し、変更ファイル・直接の利用側を個別に検査して `lake build SYK` を実行する。主要定理の公理依存とは別に残る外部仮定を確認し、関係する文書・Blueprint を更新する。3課題のどれかを再開したら、[原稿との対応](ARCHITECTURE.md#現行原稿の主張) に従って Blueprint の CLT 章の未形式化部分も更新する。読み取り調査だけの課題では、出典と仕様の照合結果を報告する。
