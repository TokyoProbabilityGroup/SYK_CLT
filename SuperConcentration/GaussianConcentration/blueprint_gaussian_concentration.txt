# Blueprint for `gaussian_lipschitz_concentration`

This blueprint matches the current file
`SYK/Gaussian_concentration/gaussian_concentration.lean`.

The file proves the SYK concentration theorem by reducing it to a reusable
finite-dimensional Gaussian concentration theorem. The only analytic input left
as `sorry` is the upper-tail concentration theorem.

## Coupling space and its dimension

The coupling space is now defined directly as a Euclidean space over the subtype
of finite subsets:

```lean
abbrev CouplingSpace (N q : Nat) :=
  EuclideanSpace Real ({s : Finset (Fin N) // s.card = q})
```

The finite coordinate count is recorded by:

```lean
@[simp]
theorem couplingSpace_card (N q : Nat) :
    Fintype.card ({s : Finset (Fin N) // s.card = q}) = Nat.choose N q := by
  simp
```

This theorem is independent of the concentration proof, but it documents the
expected SYK dimension.

## Gaussian measures

The SYK measure is the product standard Gaussian pushed forward to the
Euclidean `L2` representation:

```lean
noncomputable def standardGaussianMeasure (N q : Nat) :
    Measure (CouplingSpace N q) :=
  (Measure.pi fun _ : ({s : Finset (Fin N) // s.card = q}) => gaussianReal 0 1).map
    (WithLp.toLp 2)
```

The reusable finite-dimensional version is:

```lean
noncomputable def standardGaussianMeasureOnEuclidean
    (iota : Type*) [Fintype iota] :
    Measure (EuclideanSpace Real iota) :=
  (Measure.pi fun _ : iota => gaussianReal 0 1).map (WithLp.toLp 2)
```

The SYK measure is definitionally equal to the reusable measure at the current
index type:

```lean
@[simp]
theorem standardGaussianMeasure_eq_onEuclidean (N q : Nat) :
    standardGaussianMeasure N q =
      standardGaussianMeasureOnEuclidean ({s : Finset (Fin N) // s.card = q}) := rfl
```

The probability-measure instance is:

```lean
instance standardGaussianMeasureOnEuclidean_isProbability
    {iota : Type*} [Fintype iota] :
    IsProbabilityMeasure (standardGaussianMeasureOnEuclidean iota) := by
  unfold standardGaussianMeasureOnEuclidean
  exact Measure.isProbabilityMeasure_map
    (WithLp.measurable_toLp 2 (iota -> Real)).aemeasurable
```

This proof relies on the product Gaussian already carrying the probability
measure instance, then uses measurability of `WithLp.toLp 2`.

## Analytic input

Keep the upper-tail theorem as the single analytic input:

```lean
theorem product_standardGaussian_upper_tail
    {iota : Type*} [Fintype iota]
    (F : EuclideanSpace Real iota -> Real) (L t : Real)
    (hL : 0 < L) (ht : 0 < t)
    (hLip : LipschitzWith L.toNNReal F) :
    standardGaussianMeasureOnEuclidean iota
        {x | F x - integral (fun y => F y) (standardGaussianMeasureOnEuclidean iota) > t} <=
      ENNReal.ofReal (Real.exp (-t ^ 2 / (2 * L ^ 2))) := by

```

## Lower tail

The lower-tail theorem is derived from the upper-tail theorem applied to `-F`:

```lean
theorem product_standardGaussian_lower_tail
    {iota : Type*} [Fintype iota]
    (F : EuclideanSpace Real iota -> Real) (L t : Real)
    (hL : 0 < L) (ht : 0 < t)
    (hLip : LipschitzWith L.toNNReal F) :
    standardGaussianMeasureOnEuclidean iota
        {x | (integral (fun y => F y) (standardGaussianMeasureOnEuclidean iota)) - F x > t} <=
      ENNReal.ofReal (Real.exp (-t ^ 2 / (2 * L ^ 2))) := by
```

Current proof shape:

```lean
  convert product_standardGaussian_upper_tail (fun x => -F x) L t hL ht hLip.neg using 2;
  simp +decide [sub_eq_neg_add]
  rw [MeasureTheory.integral_neg]; ext; simp +decide [add_comm]
```

The useful facts are:

## Absolute-value helper

The two-sided argument uses the elementary real lemma:

```lean
theorem abs_gt_iff_pos_or_neg {a t : Real} :
    |a| > t <-> a > t \/ -a > t := by
  rw [abs_eq_max_neg, gt_iff_lt, gt_iff_lt, gt_iff_lt, lt_max_iff, lt_neg]
```

This lemma converts the absolute-value event into the union of the upper and
lower tail events.

## Two-sided Euclidean concentration

The reusable theorem is:

```lean
theorem euclidean_lipschitz_gaussian_concentration
    {iota : Type*} [Fintype iota]
    (F : EuclideanSpace Real iota -> Real) (L t : Real)
    (hL : 0 < L) (ht : 0 < t)
    (hLip : LipschitzWith L.toNNReal F) :
    standardGaussianMeasureOnEuclidean iota
        {x | |F x - integral (fun y => F y) (standardGaussianMeasureOnEuclidean iota)| > t} <=
      ENNReal.ofReal (2 * Real.exp (-t ^ 2 / (2 * L ^ 2))) := by
```

Proof outline:

- Set
  `hexp : 0 <= Real.exp (-t ^ 2 / (2 * L ^ 2))`
  by `Real.exp_nonneg _`.
- Prove the event inclusion
  `{x | |F x - mean| > t} subset upper_tail union lower_tail`.
- Use `abs_gt_iff_pos_or_neg` for the split.
- In the negative case, rewrite with `neg_sub`.
- Apply `measure_mono` to the event inclusion.
- Apply `measure_union_le` to bound the union.
- Apply `product_standardGaussian_upper_tail` and
  `product_standardGaussian_lower_tail`.
- Convert the final sum with
  `rw [<- ENNReal.ofReal_add hexp hexp]; congr 1; ring`.

The current proof writes `standardGaussianMeasureOnEuclidean iota` directly in
the statements.

## Final SYK theorem

The target theorem is:

```lean
theorem gaussian_lipschitz_concentration
    (N q : Nat) (F : CouplingSpace N q -> Real) (L t : Real)
    (hL : 0 < L) (ht : 0 < t)
    (hLip : LipschitzWith L.toNNReal F) :
    standardGaussianMeasure N q
        {x | |F x - integral (fun y => F y) (standardGaussianMeasure N q)| > t} <=
      ENNReal.ofReal (2 * Real.exp (-t ^ 2 / (2 * L ^ 2))) := by
  simpa using
    euclidean_lipschitz_gaussian_concentration
      (iota := ({s : Finset (Fin N) // s.card = q})) F L t hL ht hLip
```

The final proof works because `CouplingSpace N q` and `standardGaussianMeasure N q`
are definitionally the Euclidean space and Gaussian measure at the subtype
`{s : Finset (Fin N) // s.card = q}`.
