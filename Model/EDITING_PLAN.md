# 共有 SYK 模型の編集計画

## 現在の作業

Model 内に、W01–W04、W06・F04、Z01 から持ち越した実装課題はない。これらの完了範囲と検証結果は [作業履歴](../WORK_HISTORY.md#model-w01)、[CLT の統合記録](../WORK_HISTORY.md#clt-integration-audit-2026-09-29)、[Z01 の記録](../WORK_HISTORY.md#z01-local-zero-free-2026-09-28) を参照する。現行の宣言の所属・規格化・仮定は [構造文書](ARCHITECTURE.md) と Lean ソースを確認する。

固定自己共役行列についての Z01 は `[Nonempty d]` を仮定する。複素円板の半径は行列と中心の実逆温度に依存する。新しい利用側が `N` や標本に一様な非零領域を必要とする場合は、対象のハミルトニアン、有界性、一様性を指定して別課題とする。現行 CLT はその領域を入力に使わない。

CLT 内の有限模型・任意階微分の補題を他の利用側でも共有する必要が生じた場合は、実際の利用先と型・仮定を確認してから Model の適切な層への移設を検討する。現在の CLT 固有の規格化や漸近定理を先回りして移さない。
