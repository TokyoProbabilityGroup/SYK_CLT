# 共有 SYK 模型の編集計画

## 現在の作業

Model 内に、W01–W04、W06・F04、Z01 から持ち越した実装課題はない。これらの完了範囲と検証結果は [作業履歴](../WORK_HISTORY.md#model-w01)、[CLT の統合記録](../WORK_HISTORY.md#clt-integration-audit-2026-09-29)、[Z01 の記録](../WORK_HISTORY.md#z01-local-zero-free-2026-09-28) を参照する。現行の宣言の所属・規格化・仮定は [構造文書](ARCHITECTURE.md) と Lean ソースを確認する。

新しい利用側が `N` や標本に一様な非零領域を必要とする場合は、[現行結果の仮定と範囲](ARCHITECTURE.md#複素逆温度を扱う定理の仮定) を確認し、対象のハミルトニアン、有界性、一様性を指定して別課題とする。

CLT 内の有限模型・任意階微分の補題を他の利用側でも共有する必要が生じた場合は、実際の利用先と型・仮定を確認してから Model の適切な層への移設を検討する。現在の CLT 固有の規格化や漸近定理を先回りして移さない。

## CLT の数学的実装後の再設計

共有層のリファクタリングは [全体計画](../EDITING_PLAN.md#残る作業) の順序に従う。調査仕様は [CLT の計画](../CLT/EDITING_PLAN.md#数学的実装後のリファクタリング) を参照する。

Model では有限行列解析、規格化トレース、有限模型の補題の所属と実際の利用先を確認する。移設対象・利用側・数学的利点・変更前後の依存を確定してから編集し、Model から CLT への依存を作らない。規格化と公開定理の内容を保持し、変更ファイルの個別検査、Model と影響する利用側のビルド、共有層変更後の既定ビルド、公理依存の確認を行う。
